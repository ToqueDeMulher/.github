## Sobre

O **Toque de Mulher** é um projeto criado para transformar uma loja de beleza em uma operação digital mais moderna, organizada e escalável.

A plataforma oferece uma experiência simples para quem compra e uma base de gestão para quem administra a loja.

## O que a plataforma entrega

| Para clientes | Para a loja |
|---|---|
| Catálogo de produtos | Gestão de produtos |
| Busca e categorias | Controle de estoque |
| Carrinho de compras | Organização de fornecedores |
| Checkout visual | Base para pedidos e pagamentos |
| Cadastro, login e endereço | Apoio à redução de processos manuais |

## Status atual

O MVP está **demonstrável e em validação**.

A loja já pode ser apresentada, com navegação, catálogo, carrinho, checkout visual, autenticação e área administrativa. Antes da operação comercial real, os fluxos de compra, pagamento, pedido e estoque ainda precisam ser validados de ponta a ponta.

## Objetivo

Criar um canal digital para ampliar o alcance da marca, melhorar a experiência da cliente e preparar a operação para crescer online.
